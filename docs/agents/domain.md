# Domain Docs

## Перед исследованием кода

Прочитай корневой CONTEXT.md и относящиеся к задаче ADR из docs/adr/.

Если их нет, продолжай без замечаний и предложения создать их заранее.
Навык domain-modeling создаёт их по мере согласования терминов и решений.

## Структура

Single-context:
- CONTEXT.md — словарь и модель предметной области.
- docs/adr/ — архитектурные решения.

Используй термины из CONTEXT.md. Пробелы в словаре отмечай для
domain-modeling. Противоречия существующим ADR указывай явно.

Текущую документацию проекта сохраняй источником истины;
не дублируй её в новых спецификациях.
