# Triage Labels

| Роль | Метка | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется оценка |
| needs-info | needs-info | Ожидается информация от автора |
| ready-for-agent | ready-for-agent | Готово для автономного агента |
| ready-for-human | ready-for-human | Требуется реализация человеком |
| wontfix | wontfix | Выполняться не будет |

Когда навык называет роль, используй соответствующую метку.
